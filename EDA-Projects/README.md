
# Student Productivity and Digital Distraction Analysis

## 📌 Project Overview
This project focuses on analyzing student productivity and digital distraction patterns using Exploratory Data Analysis (EDA).

The main objective is to understand how study habits, sleep patterns, phone usage, social media usage, and stress levels influence students' focus scores.

## 📊 Dataset Information
- Total Records: 20,000
- Total Columns: 18
- Dataset Type: Student Productivity and Digital Distraction

## 🔍 Key Features
- Study Hours
- Sleep Hours
- Phone Usage
- Social Media Usage
- Stress Level
- Focus Score

## 🛠️ Technologies and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## ⚙️ Data Analysis Process
1. Data Loading
2. Data Understanding
3. Data Inspection
4. Checking Missing Values
5. Checking Duplicate Values
6. Exploratory Data Analysis
7. Data Visualization
8. Identifying Patterns and Insights

- No duplicate values found.

## 🎯 Project Objective
To explore the relationship between students' study habits and digital distractions and understand the factors that may influence their productivity and focus.
