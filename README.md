### 📊 2. Exploratory Data Analysis (EDA)

#### Student Productivity and Digital Distraction Analysis

**Description:**

An Exploratory Data Analysis project focused on understanding the relationship between student productivity, study habits, focus, sleep, stress, and digital distractions.

**Dataset:**
Student Productivity and Digital Distraction

**Tools & Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

**Analysis Performed:**
- Data Inspection
- Missing Value Analysis
- Duplicate Value Checking
- Descriptive Statistics
- Data Visualization
- Correlation Analysis
- Heatmap Visualization

**Key Findings:**
- Study hours have a strong positive correlation with productivity (0.733).
- Focus score has a positive correlation (0.411).
- Sleep hours have a positive correlation (0.341).
- Phone usage has a negative correlation (-0.327).
- Stress level has a negative correlation (-0.197).
